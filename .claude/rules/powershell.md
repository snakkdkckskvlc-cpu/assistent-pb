# PowerShell: BOM обязателен, эмодзи запрещены

## UTF-8 **с BOM**, иначе скрипт молча не работает

Windows PowerShell 5.1 без BOM читает файл как cp1251. Заглавная «Г» (байты
`D0 93`) превращается в типографскую кавычку и ломает разбор. Так молча не
работали пять скриптов установки (`1ac2377`) — отказ проявлялся только у
пользователя на Windows и только тишиной.

Проверяет хук `.claude/hooks/charcheck.py`, но знать надо: если правите `.ps1`
с кириллицей другим способом, BOM проставить вручную.

## ASCII-маркеры в выводе, не эмодзи

`UnicodeEncodeError: 'charmap' codec` в консоли Windows — это эмодзи в `print()`.
В проекте принято `[OK]` / `[X]` / `[!]`.

## Версия внешних инструментов — глобом, не хардкодом

Папка LanguageTool определяется шаблоном `LanguageTool-*`, а не строкой «6.6»:
апстрим-бамп версии иначе ломает свежие установки.

## bootstrap.ps1 покрыт манифестом

Любая правка установщика — правка покрытого файла, со всеми последствиями:
пересобрать `integrity.json` в том же коммите.
