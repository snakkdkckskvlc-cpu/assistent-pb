# Надёжность: база, очередь, роутеры

Переехало из CLAUDE.md §7 дословно.

## Миграции обязательны

`CREATE TABLE IF NOT EXISTS` существующую таблицу не трогает. Новый столбец у
живой таблицы доезжает только через `_MIGRATIONS` в `db.py`. Индекс по такому
столбцу — в `_POST_MIGRATION_SCHEMA`, иначе `executescript` падает на
«no such column» у всех, кто запускал прошлую версию.

## База

SQLite в WAL, `busy_timeout`. Индексы — под фактические запросы: составные там,
где фильтр идёт по двум полям сразу (`idx_trip_vehicle(vehicle_id, departed_at)`,
`idx_trip_waybill(waybill_id, seq)`). Частичный уникальный индекс, когда
уникальность нужна не для всех строк (номер листа — только у выписанных).
Разграничение доступа — через `owner` у записи и проверку в сервисе.

## Повторный запрос не должен ломать данные

Пользователь нажимает кнопку дважды. Операции, создающие документы и записи,
обязаны это переживать: уникальные индексы там, где дубль недопустим (номер
путевого листа), понятная ошибка вместо второго документа, `INSERT OR IGNORE`
в сидах.

## Очередь

Своя, в памяти (`infrastructure/queue.py`), с честностью между пользователями:
тридцать сотрудников, одна модель, и один человек с пачкой договоров не должен
занять её на час. Результаты задач переживают перезапуск сервера
(`task_results`), потому что человек ждал их минутами.

## Отказ должен быть виден

Молчаливая деградация — худший вид отказа в этом проекте, и он уже случался
трижды: письмо без фирменного бланка выглядело нормально, обрезанный промпт
давал ноль находок, скачивание молча не работало. Правило: если результат
получен в урезанном виде — сказать об этом в интерфейсе, до того как человек
отправит документ контрагенту.

## Роутеры

Новый роутер добавляется в защищённый список в `main.py::create_app` целиком, а
не обвешивается `Depends` по ручкам: ручек больше двадцати, забытая означает
открытый доступ к договорам компании из всей внутренней сети.

Чужой объект отдаёт **404, а не 403**: 403 подтверждает существование объекта.

Импорты pydantic-моделей тела запроса **нельзя** переносить в `TYPE_CHECKING` —
FastAPI разрешает аннотации при регистрации роута, и приложение упадёт на старте.
