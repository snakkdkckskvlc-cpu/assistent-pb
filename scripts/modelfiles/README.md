# Saiga Mistral 7B — как добавить в сравнение

Внешний план развития предлагал переключить `LLM_MODEL` на Saiga-Mistral-7B
(русский instruct-финтюн Mistral-7B, проект IlyaGusev/saiga) как модель по
умолчанию. Решение по этому пункту: **сначала бенчмарк, потом переключение**
(если вообще) — `config.py::LLM_MODEL` в этом коммите не меняем. Этот файл —
только про то, как поставить Saiga ЛОКАЛЬНО, чтобы включить её в сравнение
через [`../benchmark_models.py`](../benchmark_models.py).

## Что здесь проверено, а что — нет

- Механика Ollama (`ollama create` из GGUF + Modelfile, синтаксис
  `FROM`/`TEMPLATE`/`PARAMETER`) — стандартная, стабильная, проверена.
- **Формат диалога в `TEMPLATE`** (`saiga_mistral_7b.Modelfile`) — по памяти,
  НЕ проверен вживую на реальном GGUF-файле в этом прогоне (в момент
  написания на машине не было интернета для скачивания ~4.4 ГБ). Перед тем
  как полагаться на качество ответов Saiga в проде — сверьте формат диалога
  с карточкой модели на HuggingFace. Неверный формат не ломает генерацию
  (модель всё равно что-то ответит), но может ощутимо просадить качество —
  тихая деградация, а не ошибка, которую вы сразу заметите.
- Конкретное имя репозитория/файла GGUF на HuggingFace здесь намеренно не
  указано — квантованные версии и структура репозиториев меняются со
  временем. Ищите сами: HuggingFace → поиск «saiga mistral 7b gguf»,
  автор `IlyaGusev`. Берите квантование **Q4_K_M** (баланс размера и
  качества для CPU-инференса, ~4.4 ГБ) — на нём и рассчитан `num_ctx`/
  `PARAMETER` в Modelfile.

## Шаги

1. Скачайте GGUF-файл модели (Q4_K_M) с HuggingFace, положите в эту папку
   рядом с `saiga_mistral_7b.Modelfile`. Файлы `.gguf` игнорируются git'ом
   (`.gitignore`) — не коммитить, это ~4.4 ГБ бинарник.
2. Если скачанный файл называется иначе — поправьте строку `FROM` в
   `saiga_mistral_7b.Modelfile` на реальное имя файла.
3. Соберите модель в Ollama:
   ```bash
   cd scripts/modelfiles
   ollama create saiga_mistral_7b -f saiga_mistral_7b.Modelfile
   ```
4. Проверьте, что модель отвечает и по-русски, и в разумном формате:
   ```bash
   ollama run saiga_mistral_7b "Привет! Расскажи в двух словах, кто ты."
   ```
5. Добавьте в сравнение:
   ```bash
   python scripts/benchmark_models.py --models qwen2.5:7b-instruct saiga_mistral_7b
   ```
6. По цифрам (задержка первого токена, ток/с, число провалов) и — что
   важнее цифр — по реальному качеству ответов на паре тестовых документов
   из `tests/samples/` решайте, стоит ли менять `LLM_MODEL` в `config.py`.
   Смена — однострочная правка `os.environ.get("LLM_MODEL", "...")`, но
   сознательно оставлена ручным решением после теста, а не частью этого
   коммита.
