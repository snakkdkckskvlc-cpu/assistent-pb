# Пакеты рантайма для venv на Windows-машине пользователя.
#
# Единственный источник правды для bootstrap.ps1 (первая установка) и
# fire_safety_desktop.updater (автообновление) — оба ставят ровно этот
# список. Если в apps/backend, apps/desktop или packages/rag появилась
# новая внешняя зависимость — добавьте её и сюда, иначе она не попадёт
# в venv и приложение упадёт с ModuleNotFoundError.
#
# Версии намеренно НЕ закреплены (в отличие от pyproject.toml каждого
# пакета) — КРОМЕ chromadb: закреплённая chromadb==0.5.23 тянет
# chroma-hnswlib==0.7.6, для которой на чистой Windows часто нет готового
# wheel (сборка из исходников требует Visual Studio Build Tools, которых
# обычно нет) — поэтому версию не пинили вовсе. Но packages/rag/prebuilt_chroma/
# (готовая база в git — см. fire_safety_rag.seed) записана конкретной
# версией chromadb, и её on-disk формат не гарантированно читается более
# новыми версиями библиотеки. 1.5.9 — версия, которой прогнан индексатор
# при сборке текущего prebuilt_chroma; ставится через готовый wheel, без
# проблемы chroma-hnswlib. Если меняете версию — пересоберите
# prebuilt_chroma этой же версией (см. packages/rag/prebuilt_chroma/README.md).
