# Ассистент ПБ — инструкция для тестировщика

Тестировался на Windows 10 и 11. Установка ~30–40 минут, из которых 25 минут — просто скачивание модели, компьютер можно оставить.

---

## Установка — три действия

### 1. Распаковать архив

Правая кнопка на **`fire-safety-assistant.zip`** → **«Извлечь всё…»** → указать путь **без пробелов и без кириллицы**:
- ✅ Хорошо: `C:\fire-safety-assistant`
- ❌ Плохо: рабочий стол, «Мои документы», любой путь с русскими буквами.

Открыть распакованную папку.

### 2. Двойной клик по `START.bat`

Внутри папки есть файл **`START.bat`** — двойной клик по нему.

- Откроется чёрное окно с русским текстом «Ассистент ПБ — установка на Windows».
- Написано: *«Нажмите любую клавишу для продолжения»* → нажать любую клавишу.
- Пойдёт установка. Окно **не закрывайте**.

По ходу Windows несколько раз спросит **«Разрешить приложению внести изменения?»** (UAC) — это установщики Ollama и Tesseract. Каждый раз нажимайте **«Да»**.

### 3. Дождаться

В окне будут появляться шаги:
```
=== 1/8 · Python 3.13 ===          ~2 минуты
=== 2/8 · Ollama + языковая модель ===  15-25 минут (скачивание 5 ГБ)
=== 3/8 · Tesseract OCR + русский язык === 3-5 минут
=== 4/8 · Poppler ===              1 минута
=== 5/8 · Python venv + зависимости ===   3-10 минут
=== 6/8 · Индексация нормативной базы === 5-10 минут
=== 7/8 · LanguageTool (офлайн-проверка орфографии, опционально) === 1-3 минуты
=== 8/8 · Ярлык на рабочем столе === 5 секунд

=== Готово ===
```

Шаг 7/8 (LanguageTool) необязательный: если он не пройдёт (нет сети,
сайт недоступен) — установка **не остановится**, просто в этом месте
будет жёлтое предупреждение, и дальше всё пойдёт как обычно. Без
LanguageTool приложение работает нормально, просто проверка орфографии
идёт только через LLM.

Когда увидите «Готово» — установка закончилась. Нажать Enter, окно закроется.

На **рабочем столе** появится ярлык **«Ассистент ПБ»** с иконкой огонька — двойной клик, приложение запустится.

## Первый запуск — тест

Первый запуск после установки может занять **1–2 минуты** — модель прогружается в память.

В шапке окна должна быть надпись зелёным:
> ● qwen2.5:7b-instruct готова · нормативная база подключена

Готовые примеры для проверки в папке **`tests\samples\`**:
- **`spellcheck_bad.txt`** → кнопка «Проверка документа». Должна найти 5–8 ошибок.
- **`contract_short.txt`** → кнопка «Анализ договора». Должна найти 4 риска со ссылками на статьи ГК РФ.
- **`letter_draft.txt`** → кнопка «Официальное письмо». Должна создать DOCX для скачивания.

**Тайминги** (это MVP на CPU без видеокарты):
- Проверка документа: 30 сек – 3 мин на страницу.
- Анализ договора: 3–10 мин.
- Составление письма: 30–90 сек.

## Если сломалось

**Главный принцип**: окно `START.bat` не закроется само, даже при ошибке. Если что-то упало — красный текст будет видно.

### Установка упала — что прислать разработчику

1. **Сфотографировать окно** `START.bat` целиком (Win+PrtScn или скриншот).
2. **Файл `bootstrap.log`** — лежит в той же папке, где `START.bat` (например, `C:\fire-safety-assistant\bootstrap.log`). Пришлите его.
3. **Версия Windows**: Win+R → `winver` → скриншот появившегося окна.

Разработчик по этим трём вещам точно найдёт проблему.

### Частые ошибки и что делать

| Что видит тестировщик | Что делать |
|---|---|
| «SmartScreen предотвратил запуск» при кликах на Ollama/Tesseract | «Подробнее» → «Выполнить в любом случае» |
| Ошибка на шаге 2/8 (Ollama) | Обычно медленный интернет или сорвалась загрузка. Перезапустить `START.bat` — он докачает |
| Ошибка на шаге 3/8 (Tesseract) | Скачать вручную с https://github.com/UB-Mannheim/tesseract/wiki, при установке поставить галочку **Russian**, перезапустить `START.bat` |
| Жёлтое предупреждение на шаге 7/8 (LanguageTool) | Не страшно — шаг необязательный, установка продолжится. Перезапустить `START.bat` позже, если нужна проверка орфографии через LanguageTool |
| Установка прошла, но ярлыка нет | В папке проекта найти `start.bat` (маленькими буквами), двойной клик — запустит приложение. Правой кнопкой → «Отправить» → «Рабочий стол (создать ярлык)» |
| Приложение открылось, красным «Ollama недоступна» | В трее у часов должен быть значок ламы. Если нет — Пуск → напечатать «Ollama» → запустить |
| Задача идёт больше 30 минут | На слабом железе с большим документом — норма. Прогресс-таймер в окне показывает секунды. Если хочется быстрее — переменная `LLM_MODEL=qwen2.5:14b-instruct-q4_K_M` (для машин с 32+ ГБ ОЗУ) |

### Перезапуск установки

`START.bat` можно запускать сколько угодно раз. Он проверяет, что уже установлено, и пропускает готовое. Полезно, если сорвалась какая-то загрузка.

### Полное удаление

Просто удалить папку `C:\fire-safety-assistant\`. Ollama и Tesseract остаются установленными — удаляются через «Установка и удаление программ» Windows отдельно.
