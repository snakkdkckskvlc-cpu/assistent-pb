# Матрица RACI

**R** — Responsible (делает), **A** — Accountable (отвечает),
**C** — Consulted (советуется), **I** — Informed (в курсе).

## Роли

- **PO** — Product Owner (фаундер, отвечает за roadmap).
- **DEV** — Разработчик.
- **JUR** — Юрист-консультант (внешний).
- **QA** — QA/тестировщик.
- **ADM** — ИТ-администратор на стороне клиента.

## Матрица

| Активность | PO | DEV | JUR | QA | ADM |
|---|:-:|:-:|:-:|:-:|:-:|
| Продуктовое видение, roadmap | **A/R** | C | I | I | I |
| User stories, RICE | **A/R** | C | C | I | — |
| Архитектура и ADR | A | **R** | — | C | — |
| Разработка (код) | I | **A/R** | — | C | — |
| Промпты трёх функций | C | **R** | C | C | — |
| Корпус нормативных актов | I | R | **A** | C | — |
| Тексты законов, обновления | I | R | **A** | I | — |
| Unit / smoke-тесты | I | **A/R** | — | C | — |
| E2E-ручные тесты | C | R | C | **A/R** | I |
| CI-пайплайн | I | **A/R** | — | C | — |
| Документация в `docs/` | C | **A/R** | C | C | — |
| Инструкция для тестировщика | C | **R** | — | **A** | I |
| Установка на боевой сервер | I | C | — | I | **A/R** |
| Обновление модели Ollama | C | R | — | I | **A** |
| Обучение сотрудников клиента | R | C | — | C | **A** |
| Реагирование на инциденты (LLM галлюцинирует) | A | R | **C** | R | I |
| Продажи / переговоры с клиентами | **A/R** | I | I | — | I |

## Правила

- Каждая активность имеет ровно одного **A** (единственный ответственный).
- **R** может быть несколько (соавторы).
- **C** консультируются **до** решения, **I** — узнают **после**.
