## 1. Парк: 12 машин

Нужно по КАЖДОЙ машине. Проще всего — сфотографировать СТС и ПТС, там есть всё.

- [ ] Как машину называют вслух («Логан 145») — по этому имени её будут искать
- [ ] Госномер, марка, модель, год выпуска
- [ ] Категория ТС из ПТС (M1 легковая, N1/N2 грузовая) **[влияет]** — от неё
      зависят тахограф и периодичность техосмотра
- [ ] Разрешённая максимальная масса (для грузовых)
- [ ] Объём двигателя — нужен для нормы расхода
- [ ] Марка топлива (АИ-92 / АИ-95 / ДТ / газ)
- [ ] Объём бака
- [ ] Текущий пробег по одометру на день заполнения
- [ ] Есть ли на машине ГЛОНАСС

**Отдельно спросить:** есть ли уже приказ директора, утверждающий нормы расхода
топлива по каждой машине? **[блокер для расчёта топлива]** Без него расход
считать не от чего — нормы Минтранса дают базу, но конкретные цифры по парку
утверждает организация.

## 2. ГЛОНАСС — известно, что стоит на 3 грузовых

### Что за система

- [ ] Название платформы или адрес сайта, куда заходят смотреть машины
      **[блокер]** — от этого зависит, есть ли API
- [ ] Кто поставщик, есть ли договор и контакт технической поддержки
- [ ] Есть ли логин с правами администратора (не только просмотр)

### Где живут данные

- [ ] Адрес, который открывают в браузере. Если внешний сайт — данные в облаке
      поставщика; если вида `192.168.x.x` — сервер стоит внутри компании

      интернет
- [ ] Если облако: входит ли в тариф доступ по API, или это отдельные деньги

### Что именно передают трекеры

- [ ] Только координаты и пробег — или ещё что-то
- [ ] **Есть ли датчик уровня топлива.** Проверяется просто: если в системе
      есть график уровня топлива по времени — датчики стоят
- [ ] Виден ли расход топлива и заправки/сливы
- [ ] Есть ли датчик зажигания, моточасы

### Практика

- [ ] Кто и зачем сейчас смотрит в эту систему
- [ ] Совпадает ли пробег по трекеру с одометром, и насколько расходятся
- [ ] Планируется ли ставить ГЛОНАСС на остальные 9 машин, и когда
      **[влияет]** — если да, ручной ввод временный; если нет, он навсегда

## 4. 1С

- [ ] Какая конфигурация и версия (Бухгалтерия, УНФ, ERP, Управление
      автотранспортом) **[блокер]**
- [ ] Где стоит: файловая база на компьютере или сервер
- [ ] Кто её обслуживает — свой человек или подрядчик, есть ли контакт
- [ ] Ведутся ли путевые листы в 1С сейчас или только бухгалтерия
- [ ] Списывается ли ГСМ в 1С, по каким документам
- [ ] Есть ли доступ к базе для интеграции (COM, веб-сервисы, OData)
      **[блокер]** — без этого обмен возможен только файлами
- [ ] Готовы ли платить за доработку 1С, если она понадобится

**Что здесь решается.** Направление обмена: 1С → наше приложение (берём
справочник машин и цены топлива), наше → 1С (отдаём готовые путевые листы для
списания), или в обе стороны. Самый дешёвый вариант — выгрузка файлом раз в
месяц; самый удобный — прямой обмен, но он требует доступа к базе.

## Почему эти вопросы, а не другие

**Три машины с ГЛОНАСС из двенадцати** означают, что модуль нельзя строить
вокруг трекера — девять машин останутся без учёта. Правильно наоборот: ручной
ввод как основа, данные трекера как уточнение там, где он есть. Поэтому в
списке столько вопросов про нынешний бумажный порядок: он и станет каркасом.

**Путевой лист — юридический документ.** Если печатать его из приложения, он
обязан быть годным: обязательные реквизиты, отметки медосмотра и техконтроля.
Отсюда блокеры в разделе 3.

**Топливо списывается не по паспортному расходу, а по нормам, утверждённым
приказом организации** на базе распоряжения Минтранса АМ-23-р, с поправками на
зиму и город. Без приказа расчёт не на чем основать — отсюда блокер в разделе 1.

**1С определяет, где живёт истина.** Если ГСМ списывается там, наше приложение
не может быть вторым независимым источником — иначе цифры разойдутся, и
разбираться будет бухгалтер. Отсюда весь раздел 4.
