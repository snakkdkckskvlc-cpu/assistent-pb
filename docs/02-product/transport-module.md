# Модуль «Транспорт» — каркас

Состояние на 2026-08-06. Работает и пригодно к вводу данных; пять кусков ждут
ответов сотрудника (вопросы — в [transport-checklist.md](transport-checklist.md)).

## Что уже работает

**Экран** `/transport.html`, карточка на главной.

| Блок | Что делает |
|---|---|
| Выдать машину | Выбор машины и точки, водитель, цель, топливо. Одометр можно не вводить — подставится последнее известное |
| Машины в рейсе | Кнопка «Вернулась»: пробег переносится в карточку машины |
| Парк | Список машин с пробегом, нормой, состоянием; добавление и снятие |
| Постоянные точки | Справочник с расстоянием от базы |
| Журнал рейсов | Закрытые рейсы: пробег, факт топлива, расход по норме |

**API** `/api/transport/`: `states`, `vehicles` (GET/POST/PATCH/DELETE),
`places` (GET/POST/DELETE), `trips` (GET/POST), `trips/{id}/close`.

## Три решения, которые стоит понимать

**Ручной ввод — основа, трекер — уточнение.** ГЛОНАСС стоит на 3 машинах из 12.
Модуль, построенный вокруг трекера, оставил бы девять машин без учёта. Поэтому
все поля заполнимы человеком, а откуда пришла запись, помечается отдельно
(`trip.source`: `manual` / `glonass` / `1c`).

**Все величины — целые в мелких единицах:** метры, миллилитры, копейки. Топливо
складывается сотнями рейсов; накопленная погрешность float'а дала бы расхождение
с бухгалтерией, которое нечем объяснить. Пересчёт в километры и литры — на
границе API.

**Рейс ≠ путевой лист.** Рейс — одна поездка. Путевой лист — юридический
документ с отметками предрейсового медосмотра и техконтроля выпуска, без
которых он недействителен; одним листом может закрываться несколько рейсов.
Таблица `waybill` появится, когда станет известен порядок медосмотра, и
свяжется с рейсами через `trip.waybill_id`.

## Что ждёт понедельника

| Что | Чего не хватает | Где точка подключения |
|---|---|---|
| Расход по норме с коэффициентами | Приказ директора, утверждающий нормы по парку (зимняя надбавка, город) | `_row_to_trip` в services/transport.py — коэффициент домножается там и снимком пишется в рейс |
| Печать путевого листа | Как проводится предрейсовый медосмотр | Таблица `waybill` + шаблон DOCX по образцу писем |
| Подтягивание пробега из ГЛОНАСС | Что за платформа мониторинга, есть ли API, где живут данные | `vehicle.tracker_id`, `trip.source='glonass'` |
| Обмен с 1С | Конфигурация, есть ли доступ к базе | `trip.source='1c'`; направление обмена решается по разделу 4 чек-листа |
| Карта маршрутов | Список постоянных точек | `place.lat`/`place.lon` уже в схеме |
| ТО, ОСАГО, техосмотр | Периодичность и текущие сроки по каждой машине | Новая таблица `maintenance` |

Норма расхода у машины может быть пустой — тогда расход по норме не считается
вовсе и показывается только факт выдачи. Это намеренно: по этой цифре списывают
топливо, и «примерно по паспорту» здесь хуже, чем прочерк.
