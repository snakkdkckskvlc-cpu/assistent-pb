# Приоритизация по RICE

**RICE = (Reach × Impact × Confidence) / Effort**.

- **Reach** — сколько пользователей затронуто в квартал (1 — редко, 5 — все).
- **Impact** — эффект на пользователя (1 — минимальный, 3 — сильный).
- **Confidence** — уверенность в оценке (0.5–1.0).
- **Effort** — человеко-недели.
