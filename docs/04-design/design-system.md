# Дизайн-система

## Палитра

```
--bg           #f5f6f8   фон страницы
--surface      #ffffff   карточки и панели
--border       #e2e5eb   рамки
--text         #1a1d23   основной текст
--muted        #6a7280   подписи и вторичные элементы

--accent       #c8352b   акцент (кнопки, ссылки, спиннер)
--accent-dark  #a52820   hover-состояние акцента

--red          #d13c30   критический риск
--yellow       #d4a017   существенный риск
--green        #2e8f4e   информационное замечание
```

Тень: `--shadow: 0 2px 8px rgba(0, 0, 0, 0.06)`.

## Типографика

- Основной шрифт: `-apple-system, "Segoe UI", "Inter", "Helvetica Neue"`.
- Базовый размер: 15px, высота строки 1.5.
- Заголовки: h1 34px, h2 20px, h3 16px.
- Deloвой стиль в предпросмотре письма: `Times New Roman`, 15px, LH 1.6.

## Компоненты

### Кнопка `.btn`
- Основная (`.btn`): красный фон, белый текст, радиус 8px.
- Вторичная (`.btn.btn-secondary`): прозрачный фон, серая рамка.
- Disabled: серый фон, cursor: not-allowed.

### Кастомная кнопка выбора файла
- `<label for="file" class="btn btn-secondary">📎 Выбрать файл</label>`
- `<input type="file" class="visually-hidden">` — скрыт через
  `position: absolute; width: 1px; height: 1px; clip: rect(0,0,0,0)`.
- Рядом `.file-name` — показывает имя выбранного файла или «Файл не выбран».

### Спиннер `.spinner`
- 12×12 px, 2px рамка, вращается по `transform: rotate(360deg)` за 0.8s.
- Используется в блоке `.progress` во время задачи.

### Плашки риска `.finding.crit-*`
- `crit-red` — красная левая рамка 4px + красный лейбл «🔴 КРИТИЧНО».
- `crit-yellow` — жёлтая рамка + «🟡 СУЩЕСТВЕННО».
- `crit-green` — зелёная рамка + «🟢 ВНИМАНИЕ».
- Внутри: цитата (`<blockquote>`), риск, правка (зелёный фон), ссылка на
  норму (маленькая метка).

### Плашки типа ошибки `.chip.*`
- `chip.orph` — красноватый фон для орфографии.
- `chip.punct` — жёлтый для пунктуации.
- `chip.style` — синий для стиля.

## Правила UX

- **Прогресс** — только спиннер и подпись стадии («В очереди»,
  «Обработка», «Фрагмент 2/5»). Без таймера — по обратной связи
  тестировщика, счётчик секунд создавал ощущение «долго».
- **Первый запрос** после запуска — до 60 сек прогрева модели, потом быстрее.
- **Ошибки** — красная плашка `.error-box` вверху результата.
- **Загруженный файл** — имя показывается под кнопкой, чтобы пользователь
  видел, что файл прикреплён.
