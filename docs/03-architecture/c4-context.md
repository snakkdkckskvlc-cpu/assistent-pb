# C4 · Уровень 1. Контекст системы

Показывает, кто и как взаимодействует с системой «Ассистент ПБ».

```mermaid
C4Context
    title Контекст системы «Ассистент ПБ»

    Person(inzhener, "Инженер ПБ", "Проверяет свои документы")
    Person(rukovoditel, "Руководитель", "Анализирует договоры")
    Person(sekretar, "Секретарь", "Составляет письма")
    Person(admin, "ИТ-администратор", "Устанавливает и обновляет")

    System(assistant, "Ассистент ПБ", "Локальное веб/десктоп-приложение<br/>для работы с документами в сфере ПБ")

    System_Ext(ollama, "Ollama", "Локальный runtime LLM<br/>(на том же сервере)")
    System_Ext(corpus, "Нормативная база РФ", "ФЗ-69, 123-ФЗ, ППР 1479,<br/>ГК РФ, СП, КоАП")

    Rel(inzhener, assistant, "Загружает документ<br/>получает исправления")
    Rel(rukovoditel, assistant, "Загружает договор<br/>получает анализ рисков")
    Rel(sekretar, assistant, "Пишет набросок<br/>получает готовый DOCX")
    Rel(admin, assistant, "Устанавливает,<br/>дозаливает корпус")

    Rel(assistant, ollama, "HTTP<br/>127.0.0.1:11434")
    Rel(assistant, corpus, "Читает при индексации")
```

## Ключевые внешние зависимости

| Система | Роль | Как связано |
|---|---|---|
| **Ollama** | Локальный runtime для LLM (Qwen 2.5 7B/14B) | HTTP на loopback |
| **Нормативная база РФ** | Тексты законов, СП, ГОСТ | Файлы в `packages/rag/corpus/` |
| **Пользователь** | Инженер / руководитель / секретарь / админ | Веб/десктоп-UI |

## Границы

Что **входит** в систему:
- Backend (FastAPI), пайплайны трёх функций.
- RAG-модуль (`packages/rag`) с индексатором и ретривером.
- Frontend + desktop-обёртка pywebview.
- Скрипты установки/сборки.

Что **не входит**:
- Ollama и её модели (внешняя зависимость, устанавливается отдельно).
- OCR-движок Tesseract (внешняя зависимость).
- Тексты законов (поставляются отдельно, могут обновляться).
- 1С, CRM, Active Directory — интеграции запланированы, но не в MVP.
