# Матрица рисков

**Вероятность**: Н — низкая, С — средняя, В — высокая.
**Влияние**: 1 — терпимо, 2 — заметно, 3 — блокер.
**Ранг** = порядок вероятность × влияние.

| # | Риск | Категория | Вер. | Вл. | Ранг | Стратегия |
|---|---|---|:-:|:-:|:-:|---|
| R1 | Ollama не устанавливается автоматически (антивирус блокирует) | Тех. | С | 3 | 🔴 | В `bootstrap.ps1` — обход UAC + подробный лог. В инструкции — раздел «если антивирус блокирует, установить руками» |
| R2 | LLM галлюцинирует ссылки на несуществующие статьи | Продукт | С | 3 | 🔴 | RAG подгружает реальные тексты; промпт требует «требует проверки юристом» если ссылки нет; disclaimer в UI |
| R3 | Слабое железо (< 8 ГБ RAM) не тянет модель | Тех. | С | 3 | 🔴 | Fallback на 7B; в docs явно указано минимальное железо; health-endpoint показывает предупреждение |
| R4 | Тестировщик не может распаковать/запустить `.ps1` (PowerShell блокирует) | Внедрение | С | 3 | 🔴 | Обёртка `START.bat` с `-ExecutionPolicy Bypass` + инструкция |
| R5 | Обновление законов ломает индекс | Данные | Н | 3 | 🟡 | Идемпотентная индексация по SHA-256; при добавлении файлов новые чанки просто добавляются |
| R6 | OCR-скан плохо читается | Продукт | С | 2 | 🟡 | В тестах фикс-набор сканов; в UI пользователь видит извлечённый текст перед анализом |
| R7 | Конфиденциальный документ утекает через веб-туннель (используется для тестов) | Безопасность | С | 3 | 🔴 | Явное предупреждение в инструкции: тестировать через туннель только на демо-документах |
| R8 | Модель отдаёт невалидный JSON (модель 7B/quantized иногда) | Тех. | С | 2 | 🟡 | `_parse_json_loose` в `llm.py` — попытка достать JSON из markdown-обёртки; retry на границе |
| R9 | Одновременная работа 3+ пользователей на CPU-only | Тех. | Н | 2 | 🟢 | Очередь задач; таблица `tasks/` показывает позицию в очереди; в docs явно 1–3 пользователя одновременно |
| R10 | Изменение API Ollama при обновлении | Тех. | Н | 2 | 🟢 | Обёртка `infrastructure/llm.py` изолирует Ollama-специфику; переход на другой LLM-провайдер — правка одного файла |
| R11 | Разработчик один — уход/болезнь | Команда | Н | 3 | 🟡 | Максимально подробная документация; ADR журнал; CI как safety-net |
| R12 | Перерасход бюджета на разработку | Финансы | С | 2 | 🟡 | Скоуп MVP закрыт за Sprint 1; каждый следующий спринт — отдельная оценка |
