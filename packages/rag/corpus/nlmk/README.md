# Документы заказчика (ПАО «НЛМК»)

Сюда складываются нормативные документы главного заказчика: СТО, положения,
инструкции, требования к подрядным организациям. Индексируются в ОТДЕЛЬНУЮ
коллекцию `nlmk_corpus`:

    python scripts/index_corpus.py --domain nlmk

## Почему отдельно от нормативки РФ

У этих документов другой статус. СТО НЛМК — не источник права: ссылаться на
него в юридическом анализе договора как на норму нельзя. Но проверять договор
на соответствие требованиям заказчика — нужно, и это отдельная задача с
отдельным разделом отчёта. В общей выдаче два источника путались бы.

Индексация домена `pb` эту папку ПРОПУСКАЕТ (см. `indexer._domain_files`) —
обход корпуса рекурсивный, и без явного исключения документы заказчика
затянуло бы в нормативную коллекцию.

## Как наполнить

Список нужных документов — `scripts/nlmk_manifest.json` (22 документа:
справочник для подрядчиков, СТО по пожарной безопасности и огневым работам,
положения о работах повышенной опасности, примеры ППР). Загрузка:

    python scripts/fetch_nlmk_docs.py --dry-run   # посмотреть, что скачается
    python scripts/fetch_nlmk_docs.py

Обходить каталог сайта скриптом нельзя — почему именно, написано в докстринге
`fetch_nlmk_docs.py`. Пополнять манифест руками.

Метаданные (doc_type, title, source_url) дописываются в `../_meta.json`
автоматически при загрузке.
