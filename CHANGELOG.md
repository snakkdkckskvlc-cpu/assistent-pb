# Changelog

Все значимые изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [0.4.0] — 2026-07-16 · Sprint 4. Справочник адресатов + фикс-пасс

### Добавлено
- **Справочник адресатов** (SQLite, `data/app.db`): список/создание/удаление
  через `/api/addressees`, дефолтные адресаты + возможность добавлять свои
  прямо из UI (комбобокс на странице письма, даталист + сохранение).
  Тон подсказки (`tone_hint`) подтягивается в промпт письма по типу адресата.
- `apps/backend/tests/smoke/test_addressees.py` — CRUD-покрытие новой функции.

### Исправлено
- **Краш приложения при старте**: `DELETE /api/addressees/{id}` (204 + `-> None`)
  падал на этапе импорта роутера (FastAPI/Starlette assert). Добавлен
  `response_model=None`.
- **Фирменный бланк письма**: реальный `letterhead.docx` не содержал 5 из 8
  плейсхолдеров, которые уже вычислял код (`{{date}}`, `{{subject}}`,
  `{{signoff}}`, `{{sender_position}}`, `{{sender_name}}`) — тема письма, дата
  и подпись отправителя молча терялись при генерации DOCX. Плейсхолдеры
  добавлены в шаблон.
- Подстановка плейсхолдеров в DOCX переведена на однопроходный regex —
  устранён риск повторной подстановки, если значение одного поля случайно
  содержало текст вида `{{другое_поле}}`.
- Блокирующие вызовы (SQLite, генерация DOCX, OCR/парсинг загруженных
  файлов) убраны с общего event loop через `asyncio.to_thread` — раньше они
  подвешивали весь бэкенд (единственный воркер очереди) на время своей работы.
- `/api/health` пересоздавал ретривер (и заново грузил embedding-модель
  ~1.3 ГБ) на каждый вызов — переведён на закешированный singleton.
- Юридический анализ договора: 5 последовательных запросов к ChromaDB
  объединены в один батч-запрос (`retrieve_many`).
- Path traversal в загрузке файлов (`services/uploads.py`) — имя файла
  теперь санитизируется так же, как в `downloads.py`.
- Валидация справочника адресатов: пустое/из пробелов имя больше не
  проходит; уникальность и поиск по имени теперь регистронезависимы
  (`COLLATE NOCASE`) и согласованы с сортировкой в списке.
- Единый `httpx.AsyncClient` на всё приложение вместо нового соединения на
  каждый вызов Ollama; отдельный короткий connect-таймаут (5с), чтобы
  недоступная Ollama не блокировала запрос на все 15 минут read-таймаута.
- Изоляция тестов от реальных `data/app.db` и `data/outputs/`.

## [0.3.0] — 2026-07-15 · Sprint 2 (продолжение). Письмо + e-mail

### Добавлено
- **Сопроводительное e-mail** к каждому официальному письму: адрес,
  тема, тело в отдельном блоке UI с кнопкой «📋 Скопировать e-mail».
- Явная привязка к бланку ООО «ПожСервис» 2026: реквизиты в шапке,
  подпись «Директор О.Н. Сляднев», получатель в правой ячейке шапки.
- Отображение получателя в предпросмотре письма в UI.

### Изменено
- Промпт `letter.txt` расширен: добавлен объект `email` (кому/тема/тело)
  в схему JSON-ответа, few-shot пример с реальным сопроводительным
  письмом в стиле ПожСервис.
- Кнопка «📄 Скачать DOCX» подписана как «на бланке ПожСервис».
- Smoke-тесты проверяют наличие поля `email` и `_docx_path` в ответе.

### Исправлено
- Приборка проекта: убраны `preview_server.py`, `.DS_Store`, кэши
  ruff/mypy/pytest, промежуточные артефакты `AppIcon.iconset/`,
  тестовые файлы из `data/uploads` и `data/outputs`.

## [0.2.0] — 2026-07-14 · Sprint 2. Реорганизация и документация

### Изменено
- **Полностью новая структура репозитория**: monorepo `apps/` + `packages/` +
  `docs/`. Backend разбит по MVC (`models/`, `views/`, `controllers/`,
  `services/`, `infrastructure/`, `pipelines/`).
- RAG вынесен в самостоятельный пакет `packages/rag` (`fire_safety_rag`),
  теперь не зависит от backend'а и переиспользуем.
- Frontend и pywebview-обёртка переехали в `apps/desktop/`.
- Единый `pyproject.toml` через uv workspaces + тонкие манифесты в пакетах.

### Добавлено
- Документация в `docs/` по разделам эталонного вузовского IT-проекта:
  vision (Elevator Pitch, Lean Canvas), product (User Stories, RICE),
  architecture (C4, DDD, ER, ADR), design (wireframes), quality (BDD,
  риски), team (Hiring Plan, Team Rituals), ops (установка на Windows/macOS).
- Smoke-тесты (`pytest`) для `/api/health` и трёх пайплайнов с моком LLM.
- Юнит-тесты чанкера RAG.
- CI GitHub Actions: `ruff check`, `ruff format --check`, `mypy`, `pytest`.
- `LICENSE` (MIT), `CHANGELOG.md`, `CONTRIBUTING.md`, `.editorconfig`,
  `.env.example`, `ruff.toml`, `mypy.ini`.

### Исправлено
- Клик по подписи «Загрузить файл» теперь открывает диалог выбора файла
  (`<label for="file">`, скрытый `<input>`, кастомная кнопка `.btn`).
- Убран таймер обработки — прогресс показывается только спиннером.
- `TaskQueue` создаёт `asyncio.Queue` в `start()`, а не при импорте — иначе
  не работала в многократных event loop'ах (в частности в тестах).
- Замена deprecated `datetime.utcnow()` на `datetime.now(timezone.utc)`.

## [0.1.0] — 2026-07-10 · Sprint 1. MVP

### Добавлено
- Три функции: проверка орфографии/пунктуации/стиля, юр. анализ договоров
  с RAG-подсказками по ФЗ/ГК РФ, генерация официальных писем на бланке.
- Backend на FastAPI + очередь на один воркер.
- Локальный LLM через Ollama (qwen2.5:7b-instruct для тестов,
  qwen2.5:14b-instruct-q4_K_M для боевого сервера).
- RAG на ChromaDB + `multilingual-e5-large`, корпус: ФЗ-69, 123-ФЗ,
  ППР 1479, ГК РФ ч.1-2, СП 3.13130/4.13130, КоАП 20.4.
- Парсеры DOCX / PDF / OCR (Tesseract + Poppler).
- Frontend — SPA-ish (HTML + vanilla JS + CSS).
- pywebview-обёртка с иконкой и `.app` бандлом для macOS.
- `bootstrap.ps1` — автоматическая установка на Windows.
